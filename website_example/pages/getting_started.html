About the algorithm (cn_turtle_lite_slow_hash_v2)

cn_turtle_lite_slow_hash_v2 is Kryptokrona's own real CryptoNight-family hash (variant 2 math, i.e. the same division/sqrt mixing step Monero's own CryptoNight v2 added, but over a much smaller 256 KB scratchpad instead of 2 MB), computed over the pool's own block-hashing blob (header fields, merkle root, transaction count -- the same general shape every CryptoNote-nodejs-pool coin uses). It is genuinely NOT the same algorithm as cn-pico/cryptonight-turtle already built into this fork, despite very similar names and matching memory/iteration parameters on paper -- confirmed by hashing the same input both ways against the real node's own code and getting different results. The wire protocol itself is the plain cryptonote-nodejs-pool Stratum (a login request, job with blob+target, submit with nonce+result), not classic Bitcoin Stratum either. A stock XMRig does not know this exact algorithm: use poolpayminer, which supports it out of the box.

Rewards and payments

  • Reward scheme: PROP (proportional, default) or solo (prefix your address with solo:).
  • Block reward follows Kryptokrona's standard CryptoNote emission curve -- see the current value on the Dashboard page.
  • Blocks are credited to your balance after 70 confirmations (Kryptokrona's real coinbase maturity is 20 blocks; the pool waits longer to be safe).
  • Payments are currently dry-run only. This will be enabled once a real block matures and the first payout is verified end to end -- it is not a bug, it is an honestly incomplete step at launch.

Об алгоритме (cn_turtle_lite_slow_hash_v2)

cn_turtle_lite_slow_hash_v2 — собственный настоящий хэш Kryptokrona семейства CryptoNight (математика variant 2, тот же шаг деления/sqrt, что и в CryptoNight v2 у Monero, но над гораздо меньшим scratchpad — 256 КБ вместо 2 МБ), вычисляемый над блоком-хэшинг-блобом пула (поля заголовка, merkle root, число транзакций — та же общая форма, что у других монет на cryptonote-nodejs-pool). Это действительно НЕ тот же алгоритм, что уже встроен в этот форк как cn-pico/cryptonight-turtle, несмотря на очень похожие названия и совпадающие на бумаге параметры памяти/итераций — проверено хэшированием одного и того же входа обоими способами на реальном коде узла, результаты разные. Сам протокол — это обычный Stratum cryptonote-nodejs-pool (запрос login, задание job с blob+target, отправка submit с nonce+result), а не классический Bitcoin Stratum. Обычный XMRig не знает именно этот алгоритм: используйте poolpayminer — он поддерживает его "из коробки".

Награды и выплаты

  • Схема наград: PROP (пропорциональная, по умолчанию) или solo (добавьте solo: перед адресом).
  • Награда за блок следует стандартной эмиссионной кривой CryptoNote — текущее значение см. на странице "Главная".
  • После нахождения блока награда зачисляется на баланс после 70 подтверждений (реальный coinbase maturity Kryptokrona — 20 блоков, пул ждёт дольше для надёжности).
  • Выплаты сейчас только в тестовом режиме (dry-run). Это будет включено после того, как реальный блок созреет и первая выплата будет проверена целиком — это не ошибка, а честно незавершённый на старте шаг.
